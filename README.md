# SNHU CS-405 Portfolio

This repository contains my coursework for SNHU's CS-405 Secure Coding course, including two projects developed for Green Pace, a fictional organization used to demonstrate secure coding practices and security policy implementation. It also includes the C++ source code from course assignments and my final journal reflection.

## Project One Security Policy

This document establishes Green Pace's secure coding standards and security policies, including risk assessment, vulnerability mitigation, access control, and data protection. It provides a framework for incorporating security throughout the software development lifecycle.
